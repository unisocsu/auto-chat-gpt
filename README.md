# Auto Chat GPT

סקריפט קל להרצה בכל כרטיסיית ChatGPT בנפרד.

## מה הוא עושה

- מזהה שסיום התשובה הגיע.
- אם סוף התשובה הוא `דרושה הנחייה` — עוצר ומפעיל התראה.
- אחרת שולח אוטומטית `תמשיך`.
- כל כרטיסייה מנהלת state עצמאי.
- כולל מנגנון הגנה כדי לא לשלוח `תמשיך` פעמיים לאותה תשובה.

## הפעלה

פתח את `auto-chat-gpt.js`, העתק את התוכן והריץ אותו ב-DevTools Console של כרטיסיית ChatGPT.

> ממשק ChatGPT משתנה מעת לעת, ולכן selectors עשויים להזדקק לעדכון בעתיד.

## מצב

גרסה ראשונית — זיהוי תשובות, שליחת "תמשיך", עצירה על "דרושה הנחייה" והתראה.
